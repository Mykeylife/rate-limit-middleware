# Security Policy

## Supported Versions

We actively monitor and provide security patches for the following core application deployment versions:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

If you discover a security vulnerability or vector leak inside this gateway proxy architecture (such as an exploit bypassing the rate-limiting middleware or SQLite injection vulnerabilities), please report it responsibly by opening a draft advisory on the GitHub **Security** tab of this repository.

Alternatively, you can contact the core maintainer directly via secure electronic mail at: **mykeylife6@gmail.com**

### Please include the following details in your report:
1. A clear description of the vulnerability behavior type.
2. Step-by-step instructions or proof-of-concept (PoC) scripts to reproduce the exploit state.
3. Potential impacts on runtime storage persistence or consumer data blocks.

We will acknowledge receipt of your vulnerability report within 48 hours and provide a detailed timeline for addressing the issue.
